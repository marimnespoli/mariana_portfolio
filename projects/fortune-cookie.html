The Goal

Build a playful, tactile fortune cookie experience in the browser — one click to break, one reveal to read. No filler content, no extra steps.

The challenge: make a simple interaction feel satisfying through animation and visual design. The entire app lives in a single gesture.

02

The Approach

Conceived in Figma with custom illustrations made in Adobe Illustrator. Visual identity draws from Chinese New Year aesthetics — warm tones, decorative patterns, hand-crafted assets.

Implemented with Next.js and TypeScript via the Figma MCP, translating the design directly into a working React component tree.

Component Tree

react

Cookie state lives in a single parent component. Child components receive props — no prop drilling, no global state needed for a single-interaction app.

type CookieState =
  | "idle"
  | "breaking"
  | "revealed";

export default function Cookie() {
  const [state, setState] =
    useState<CookieState>("idle");
  const fortune = useFortune();

  return (
    <CookieShell
      state={state}
      onBreak={() =>
        setState("breaking")}
      fortune={fortune}
    />
  );
}

Fortune Hook

hook

A custom hook picks a random fortune from the list on mount — one call, one result, immutable for the session. No side effects on re-render.

const fortunes: string[] = [
  "A dream you have will come true.",
  "You will find treasure...",
  // ...
];

export function useFortune() {
  const [fortune] = useState(() =>
    fortunes[
      Math.floor(
        Math.random() * fortunes.length
      )
    ]
  );
  return fortune;
}

Animation

css

Cookie break uses a CSS keyframe applied via a state-driven class. Tailwind utilities handle the reveal fade — no JS animation library needed.

@keyframes crumble {
  0%   { transform: rotate(0deg)
                    scale(1); }
  40%  { transform: rotate(-8deg)
                    scale(1.05); }
  70%  { transform: rotate(6deg)
                    scale(0.95); }
  100% { transform: rotate(0deg)
                    scale(0)
         opacity: 0; }
}

.breaking {
  animation: crumble 0.5s
    ease-in forwards;
}
