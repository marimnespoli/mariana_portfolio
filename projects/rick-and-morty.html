The Goal

Build a character explorer that talks to a real public API — no mock data, no shortcuts. Users needed to search and filter Rick and Morty characters in real time, with multiple filters working simultaneously.

The constraint: no frameworks. Just TypeScript, the native Fetch API, and CSS. Every abstraction had to be hand-rolled.
