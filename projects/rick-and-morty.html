Rick and Morty API

Frontend Developer  ·  TypeScript  ·  2024

A character explorer powered by the Rick and Morty public API. Search and filter characters in real time — by name, status, species, and gender. Built with TypeScript and no frameworks, focusing on clean async logic and a responsive interface.

View Live ↗ GitHub ↗

What it does

Search and filter Rick and Morty characters by name, status, species, and gender. All filters combine simultaneously in real time against the public API — no page reloads, no frameworks.

How I built it

TypeScript for type-safe API calls, async/await fetch with dynamic query parameters, and pure CSS Grid for the responsive card layout. The key challenge was combining multiple filters into a single state object that rebuilds the URL on every change.
