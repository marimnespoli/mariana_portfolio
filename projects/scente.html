The Goal

Design and build an editorial candle brand website with an autumn soul — warm tones, intentional layout, and a product grid that feels curated, not generic.

The constraint: pure HTML and CSS, no JavaScript. Every layout had to be solved through the cascade — flexbox, grid, and carefully chosen breakpoints.

02

The Approach

Responsive-first from the start. Each section was designed simultaneously for desktop, tablet, and mobile — not adapted after the fact. Breakpoints follow content needs, not arbitrary device widths.

Typography and spacing scale fluidly. The visual identity — warm cream tones, serif accents, editorial whitespace — stays consistent across every viewport.

Technical Highlights

CSS Grid Layout

layout

Product grid adapts from 3 columns on desktop to 2 on tablet to 1 on mobile — all in CSS, no JS resize listeners needed.

.product-grid {
  display: grid;
  grid-template-columns:
    repeat(3, 1fr);
  gap: 32px;
}

@media (max-width: 768px) {
  .product-grid {
    grid-template-columns:
      repeat(2, 1fr);
    gap: 20px;
  }
}

@media (max-width: 480px) {
  .product-grid {
    grid-template-columns: 1fr;
  }
}

Fluid Typography

type

Hero headline scales between viewport widths using clamp() — no hard breakpoints needed for type, no layout shift between sizes.

.hero__title {
  font-size: clamp(
    2rem,
    5vw + 1rem,
    5.5rem
  );
  line-height: 1.05;
  letter-spacing: -0.03em;
}

.hero__sub {
  font-size: clamp(
    0.9rem,
    1.5vw + 0.5rem,
    1.25rem
  );
  color: var(--muted);
}

Nav Collapse

responsive

Navigation collapses to a stacked layout on mobile using flexbox direction change — no hamburger menu JS, just a CSS-driven reflow.

.nav {
  display: flex;
  align-items: center;
  gap: 40px;
}

@media (max-width: 600px) {
  .nav {
    flex-direction: column;
    align-items: flex-start;
    gap: 16px;
    padding: 20px 0;
  }

  .nav__logo {
    margin-bottom: 4px;
  }
}

Brand Tokens

css vars

All brand colours and spacing live in CSS custom properties on :root — one change propagates site-wide, keeping the autumn palette consistent.

:root {
  --cream:   #F5EFE6;
  --warm:    #C8A97E;
  --dark:    #2C1F14;
  --muted:   #8A7562;

  --space-xs: 8px;
  --space-sm: 16px;
  --space-md: 32px;
  --space-lg: 64px;
  --space-xl: 120px;

  --radius:  4px;
  --radius-lg: 12px;
}
